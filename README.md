# quant-vn-learn

## Học Quantitative Finance từ Zero — Vietnamese Equities

### Mục tiêu
Xây dựng nền tảng quant từ số 0, hướng tới hiểu biết sâu và thỏa mãn trí tuệ.

### Lộ trình học

1. **Nền tảng** — Python, Data Science, Tài chính cơ bản, Toán
2. **Dữ liệu + Phân tích** — VN data, EDA, Visualization
3. **Quant Cơ bản** — Factor investing, Backtesting
4. **Quant Chuyên sâu** — Multi-factor, Portfolio optimization, Statistical rigor
5. **Research + Production** — Methodology, Reports, Production code

### Output
- Jupyter Notebooks (learning)
- Scripts (production-ready)
- Research Papers (academic style)

### Thị trường
Vietnamese Equities (HOSE/VN-Index)

### Tác giả
Học viên quant — bắt đầu từ zero
